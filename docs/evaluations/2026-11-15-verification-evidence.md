# 完了条件とゲートの固定課題（2026-11-15）

## 問い

検証の正常終了を依頼の達成と取り違えず、検査自身が壊れた版を捕まえることを、次の実行者も確かめられるか。

## 方法

`scripts/lib/evaluate-gate.mjs` で、一時 git リポジトリ、profile、ゲート状態を用意し、実際の `gate.sh` と hook を動かした。期待値は実装から導出せず、7つの固定課題へ明示した。外部接続・追加依存・インストール済み hook の改変は行っていない。

課題は、未arm、正常な検査、失敗する検査、未記録の委譲、profile 不一致、変更を受け持つ検査なし、Cursor の赤。終了コードに加え、検査が実際に書いたファイル、JSON の未検証情報・続行要求を観測した。故障版は拒否の終了コード・未検査のガード・Cursor の応答キーをそれぞれ壊した。作業用領域を削除した後も生出力と対象を保持し、保存した対象から再評価できること、既存の証拠を上書きしないことをテストした。

## 観測

変更前後の hook に同じ評価器を適用した。変更前は未検査の課題が不一致となった。`verify` が意図して exit 1 を返すと、Stop 用の終了処理が exit 2 へ変換し、「ゲートが想定外に終了した」と追加していた。変更後は exit 1、`checked: false`、`kind: not_checked` となり、正常版の7課題がすべて一致した。

| 故障注入 | 変更後に不一致となった課題 |
|---|---|
| 拒否の終了コードを消す | 失敗する検査、未記録の委譲 |
| 未検査の変更を受け入れる | 変更を受け持つ検査なし |
| Cursor の応答キーを壊す | Cursor の赤 |

追加テストは評価器を作る前に失敗を確認した。保存した対象の再実行も、保存形式を直す前には失敗した。Cursor の続行要求の欠落を誤通過へ数えるテストも、集計修正前に失敗を確認した。固定課題は既存の dry 実行の誤報を再現し、hook の修正後に成功した。

## 再実行と限界

コマンドと成果物の構成は [検証の説明](../verification.md) にある。各実行の JSON に、正常版の実バイト列・SHA-256・評価器・OS・Node・入力・コマンド・生出力・所要時間を残す。旧版と新版の比較では評価器のハッシュを揃える。

この比較はゲートの決められた挙動についてのもので、AIレビューの誤検知率・見逃し率・トークン費用の測定ではない。文書の指示が各ホストで選択・実行されること、全状態遷移、全故障の検出も証明していない。形式検証と実アプリ内での経路確認は未実施。

初回の元の作業ツリーでの検証には、変更前から `.venv`・`node_modules` を lint が指示ファイルとして読む5件の失敗があった。依存物を消して通過とはせず、元の失敗と、追跡ソースに今回の追加を反映した一時コピーの検証を区別した。sandbox 内では既存のメディア検査も失敗したが、同じコマンドを sandbox 外で実行すると成功した。

一時コピーの `scripts/check.sh` は、メディアの2検査だけが sandbox 制限で失敗し、それ以外はすべて成功した。既存のゲートテストは元の作業ツリーでも161件成功した。最終差分を反映した一時コピーでは、sandbox 外の `scripts/gate.sh verify --json` が終了0、`ok: true`、`checked: true` となった。差分の対象外で省略したチェックはJSONの `skipped` に残した。この段階では元の作業ツリー全体が緑になったとは主張しなかった。インストール済み hook の更新も行っていない。

## 終了ゲート後の追加修正

終了ゲートが初回に残した5件で止まったため、依存物を置いたまま実物のリンターを通す回帰テストを追加した。生成済み依存物のケースだけが失敗し、実際の `reference/` に置いた同じ3種類の不備はすべて検出された。その失敗を確認してから、シンボリックリンク・機密パターン・相対リンクの再帰走査を共通化し、`node_modules` と `.venv` のディレクトリを走査対象から外した。実際の本文と参照ファイルの検査は維持する。

追加修正後は、元の作業ツリーの lint が終了0（既存の警告14件）、lint hook とリンターの結合テストが71件成功した。元の作業ツリーでの sandbox 外の `gate.sh verify --json` も終了0、`ok: true`、`checked: true`。該当する15チェックが成功し、対象外の3チェックは `skipped` に記録された。その結果を確認してからゲートを解除した。先の一時コピーの測定と、この追加修正後の測定は別の結果として扱う。
